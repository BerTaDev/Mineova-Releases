# Mineova — güncelleme sunucusu

Bu depo **Mineova Başlatıcı**'nın oyun güncellemelerini indirdiği yerdir. Elle bir şey indirmene gerek yok:
oyunu [itch.io sayfasından](https://bertadev.itch.io/mineova) kurduğun başlatıcı her açılışta buraya bakar ve yeni sürümü kendisi indirir.

- `manifest.json` — en son sürüm, paket adresleri ve haberler
- `packages/` — şifreli oyun paketleri (`.dpak`)

> Mineova'nın eski adı *Derinova* idi. Eski Derinova sürümlerini kullanıyorsan oyunu itch.io sayfasından yeniden indir; dünyaların ve ayarların kendiliğinden taşınır.

---

This repository is where the **Mineova Launcher** downloads game updates from. You don't need to download anything here:
install the launcher from [itch.io](https://bertadev.itch.io/mineova) and it keeps the game up to date. Mineova was formerly called *Derinova*.
