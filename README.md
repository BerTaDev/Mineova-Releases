# Derinova — güncelleme sunucusu

Bu depo **Derinova Başlatıcı**'nın oyun güncellemelerini indirdiği yerdir. Elle bir şey indirmene gerek yok:
oyunu [itch.io sayfasından](https://bertadev.itch.io/derinova) kurduğun başlatıcı her açılışta buraya bakar.

- `manifest.json` — en son sürüm, paket adresleri ve haberler
- `packages/` — şifreli oyun paketleri (`.dpak`)

This repository is where the **Derinova Launcher** downloads game updates from.
Get the game from [itch.io](https://bertadev.itch.io/derinova). © BerTaDEV — all rights reserved.
